ERC-20 token transfer

Enter an ERC-20 contract to check the connected account’s balance.

Token balances can be read from a known ERC-20 contract. If the extension cannot answer read requests, this bridge falls back to a public chain RPC for balance lookup. EVM wallets do not expose a standard RPC method to enumerate every token held by an address.
